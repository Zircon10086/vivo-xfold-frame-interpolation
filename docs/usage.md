# 使用

## WebUI 入口

KernelSU 管理器 → 模块 → 本模块卡片 → 左下角按钮。

## 主页面

| 区域 | 说明 |
|---|---|
| 状态卡 | 能力节点 / 配置声明 / 当前请求值 / 生效值；「重启游戏助手」「重新应用能力」「刷新」|
| 导入应用 | 打开应用选择面板，默认只列用户应用（52 个左右），可勾选「显示系统应用」展开全部 |
| 管理当前应用 | 已导入的应用列表，可逐个移除 |
| 说明 | 三档含义、系统应用限制、恢复出厂设置入口 |

### 进入页面时会自动清理

每次打开 WebUI 会删除游戏魔盒里「本机没安装」的预置游戏行（备份在 `/data/local/tmp/vivo-memc-backup/`）。
这一步是为了让列表只反映真实可用的应用。若 `pm list packages` 结果少于 50 条（异常环境），清理会中止。

## 导入 / 移除

- 导入：面板里点「导入」→ 立即写入插帧行，应用卡片出现在「管理当前应用」。
- 移除：卡片右侧「移除」→ 二次确认 → 删除该应用下由本模块写入的行（应用本身不受影响）。
- 移除后回到导入面板，该应用会立即恢复为「导入」按钮（不会残留「已导入」状态）。

## 游戏内切换档位

1. 从屏幕左边缘上部向内滑动，呼出游戏侧栏。
2. 游戏工具 → 滚动到底 → **游戏插帧**。
3. 三个选项：

| 选项 | 效果 | 系统请求值 |
|---|---|---|
| 原始帧率 | 关闭插帧 | `0:-1:pid:0:0` |
| 提升帧率 | 60 → 120（2×） | `1:9:pid:60:120` |
| 优化功耗 | 30 → 60（2×，渲染减半） | `1:9:pid:30:60` |

切换后立即生效，不需要重启游戏。当前档位由游戏魔盒自己保存。

## 验证是否生效

```bash
adb shell settings get system gamecube_frame_interpolation   # 期望 1:9:<pid>:60:120
adb shell settings get system gamecube_memc_effective        # 期望 60（表示 60→120）
adb shell su -c 'cat /sys/rsc/vgarph/MEMC'                   # 期望 1
```

## 系统应用

大多数系统应用没有悬浮窗权限，导入后游戏侧栏不会出现，插帧也就无从开启——这是系统限制，不是模块 bug。
例外：相机这类有悬浮窗权限的系统应用可以正常插帧（实测预览从 30fps 提到 120fps）。
